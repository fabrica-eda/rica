# Sv39 実装計画

2026-10-06。[OS/ISA計画](RV64_OS_ISA_PLAN.md) §3の3段目。[S-mode](RV64_SUPERVISOR_PLATFORM.md)
（Bare）の上に、Sv39のアドレス変換を `ENABLE_SV39`（`ENABLE_S` が前提）で追加する。
目標は112/56 MHzを維持したまま、S-kernelが隔離されたU-taskを動かせること。

## アーキテクチャ上の選択

| 項目 | 選択 |
| --- | --- |
| `satp.MODE` | Bare（0）とSv39（8）。他の値の書込みは無効（仕様どおり書込み全体を無視） |
| ASID | 幅0（`satp.ASID` は0固定）。`satp` 書込みとSFENCE.VMAでTLBを全消去 |
| `satp.PPN` | 物理アドレス32 bitに収まる20 bitを保持。上位は0固定（WARL） |
| A/Dビット | Svade：A=0、またはstore/AMOでD=0のときはページフォールト。ハードウェアは書き換えない |
| ページサイズ | 4 KiB／2 MiB／1 GiB。整列していないsuperpageはページフォールト |
| 物理アドレス | 32 bit。PTEのPPNが32 bitを超える場合はアクセスフォールト（上位を切り捨てて別名にしない） |
| PTEの予約ビット | N/PBMT/予約（63:54）が0でなければページフォールト |
| VAの正規形 | bit 63:39がbit 38と一致しなければページフォールト |
| SUM/MXR | 実装。`sstatus.SUM` は書込み可能になる |
| MPRV | MPP=S/Uのとき、Mのload/storeも変換する（フェッチは変換しない） |
| ページ跨ぎ | 命令：2ページ目を別に変換。データ：ページを跨ぐ非整列アクセスはaddress-misaligned例外（仕様上許される） |
| フォールト時のxtval | フォールトしたVA。命令の2パーセル目なら2パーセル目のVA |

## 構成

既存のPMP権限キャッシュ（[RV64_PMP_PERMISSION_CACHE.md](RV64_PMP_PERMISSION_CACHE.md)）の
「ページタグ付き1エントリ＋ミス時に止めて評価」の形を、変換にも使う。

### データ側（DTLB）

- EXで、PMPのデータ権限キャッシュと同じく、転送元3候補のベースページ一致を加算器と並列に取る。
  ヒット時の物理アドレスは `{ppn, sum[11:0]}` で、上位20 bitはレジスタからそのまま入る。
  `cm_lsu_address_q` はもともとレジスタなので、加算後の比較を要求経路に足さない。
- エントリは仮想ページ・物理ページ・PTE権限（R/W/X/U/D）・ページサイズ。
  PMP権限は物理ページについて既存の評価を通す。
- ミスの命令は要求を出さず、CMでウォーカーを動かしてから再実行する（下記）。

### 命令側（ITLB）

- I-cacheは物理インデックス・物理タグのまま。コアの `pc` 出力を `{cur_ppn, va[11:0]}` にする。
  上位20 bitはレジスタのmuxで、加算器を通らない。
- I-cacheの後続行（next/ahead line）がページを跨ぐときは、次ページのPPN（`next_ppn` 入力）を使う。
  Bareでは `next_ppn = 現ページ+1`（コアがレジスタで用意）。
- 「現ページ」と「次ページ」の2エントリ。FDで、命令の先頭パーセルのVAページが現ページに、
  2パーセル目が現ページか次ページに一致することを確かめる。不一致はミスとして止め、
  変換を入れ替え・取得したあと、その命令のVAから再フェッチする。エントリは再フェッチの
  前にしか変わらないので、FDに来た命令は検査に使ったエントリで取り込まれている。

### ミスの扱い（CMでのリプレイ）

TLBミスの命令はメモリ要求を出さず、例外と同じようにCMまで進む。CMでは最古の命令なので、
先行するload/storeは退役済みでデータポートが空いている（loadの結果はCM退役時に
`data_rdata` から取るため、先行loadがCMにいる間はポートを使えない）。そこでウォーカーが
PTEを最大3回読み、TLBを埋め、その命令のPCへリダイレクトして再実行する。ミスの代償は
再フェッチとウォークで、ウォーカーはどの高速経路にも入らない。

- ページ違反はウォーク結果、またはヒット時の権限（各サイクルに現在の特権・SUM・MXRから
  登録したもの）で決まり、CMで原因12/13/15・xtval=VAの例外になる。
- PTEの読み出しはSと同じくPMPを適用し、RAM外・PMP違反はアクセス違反（命令1、load 5、store 7）。
- データのページ跨ぎはヒットにならず、CMで原因4/6（misaligned）になる。
- PMPはTLBが出す物理ページで既存の権限キャッシュ・正確検査を使う。xtvalのためCMはVAも保持する。
- `satp` 書込みとSFENCE.VMAは両TLBを消し、後続を再フェッチする（FENCE.Iと同じ直列化、I-cacheは消さない）。
  特権やSUM/MXRの変化はTLBの中身を変えない（権限は毎サイクル登録し直す）。

## 段階

1. **CSRとトラップ**：`satp`（Bare/Sv39）、SUM、ページフォールト原因12/13/15、xtvalにVA。
   変換はまだ無効（MODE=8を書けるが、TLBなしでは使わない設定で試験）。
2. **ウォーカーとDTLB**：データの変換・権限・フォールト。命令はBareのまま（S/Uのフェッチは
   変換なしのページで動く範囲で試験）。
3. **ITLB**：物理 `pc`、I-cacheの次ページPPN、FD検査と再フェッチ、命令ページフォールト。
4. **試験**：ページテーブルを組んだアセンブリ試験（4 KiB/2 MiB/1 GiB、権限、SUM/MXR、A/D、
   正規形、跨ぎ、SFENCE.VMA、`satp` 切替）、変異試験、既存270 ELFの回帰。
5. **S-kernel**：M firmware → S-kernel → 隔離されたU-task（現在のU/PMPカーネルの移植）。
6. **タイミングと実機**：112/56 MHz、チェック付きbitgen、実機。

各段でnative・同時クロックモデル・既存回帰を通してから次へ進む。

## 進捗

### 1段目（CSR）・2段目（データ側）：実装済み

- `CsrFile`：`satp`（MODE 0/8のみ受理、PPNが20 bitを超える書込みは全体を無視、ASIDは0固定）、
  SUM、変換の有効条件（`translate_data`：実効特権がS/U、MPRVを含む）。
- `PageTableWalker`：Idle→Check→Issue→Wait。PTE読み出しごとに呼び出し側のPMA/PMP判定
  （登録済み）を1サイクル後に見る。`verify/tests/page_table_walker.rs` で参照モデルと照合
  （指定ケース＋構造化した乱数テーブル、結果の種類ごとに5%以上の網羅を確認）。
- `Core`（`g_sv39`）：変換対象のload/store/atomicはEXで要求を出さず（EXのPMP判定も行わない）、
  CMで変換する。CMの状態機械はIdle→（Walk）→Verdict→Decide→Issue→Done。
  - Idle：正規形、ページ跨ぎ（→misaligned 4/6）、DTLB（1エントリ、4 KiB単位）のヒット判定と
    ヒット時の権限（現在の特権・SUM・MXRで毎回判定）。ミスはウォーカーを起動。
  - Verdict/Decide：物理アドレスに対するPMAとPMP（S/U扱い）を1つの検査器で評価し登録。
    ウォーカーのPTE読み出しも同じ検査器を使う。
  - Issue：非atomicは物理アドレスで要求を出す。atomicはDoneを待ってからatomicユニットを起動する
    （ユニットには物理アドレスを渡す）。
  - データポートはCM中の変換命令が専有し、ウォーク中はPTE読み出し（8バイト、符号なし、書込みなし）
    に使う。ブートROMページは非変換時と同じく物理アドレスから再配置する。
  - xtvalは常にVA（`cm_lsu_address_q`）。委譲はCMで原因から `exception_delegated` を引く。
- SFENCE.VMAはFENCE.Iと同じ直列化経路に載せた（I-cacheも無効化する。物理タグなので不要だが、
  経路を共有する方が単純なため）。`satp` 書込みのretireとSFENCE.VMAでDTLBとITLBを消す。

### 3段目（命令側）：実装済み

- ITLBは2エントリ（ページ、ページ−1、フレーム、権限）、ラウンドロビン置換。直前に埋めた
  エントリを次の補充が追い出さないので、ページを跨ぐ命令の2ページは必ず共存する。
- フロントエンド：フェッチVAのページをITLBと比較し、`pc` 出力（I-cacheへ）を
  `{フレーム, VA[11:0]}` にする。次ページのフレーム（`ページ−1` との一致）を `fetch_next_page`
  としてI-cacheへ渡す。ヒットしなくても任意のフレームでフェッチし、FDで捨てる。
- I-cache：`translate` 時、ページ最終行の次の行（next/ahead）を `next_page` から作る。
  奇数バンクから偶数バンクへの後続ヒット判定も、ページ境界では `next_page` の行と直接比較する。
- FD→RX：FDの命令のVAで同じ表を引き、非正規形・ミス・X/U違反を（ページを跨ぐ32 bit命令は
  2パーセル目のページも）記録する。PMPのフェッチ検査は物理アドレスで行い、ページを跨ぐ命令は
  1パーセル目だけを既存の検査器で、2パーセル目（次フレームの先頭2バイト）を別の検査器で見る。
  PMAは物理フレームについてRXで検査する（VAに対する従来の検査は変換時は無効）。
- 例外の優先順位：1パーセル目のページ違反＞1パーセル目のPMP/PMA違反＞2パーセル目のページ違反＞
  2パーセル目のアクセス違反。xepcは命令のVA、xtvalは違反したパーセルのVA。
- ITLBミスは例外と同じくCMまで進み（副作用なし）、CMでウォークしてITLBを埋め、その命令のPCへ
  リダイレクトして再フェッチする（リプレイ）。ウォークの違反は命令ページ違反12／アクセス違反1。
  権限は再フェッチ時にFDが判定する。
